# 英语精读实验室 (English Lab)

一个基于 AI 的模块化英语学习工具，帮助用户通过深度解析、词汇管理和多种记忆模式提升英语能力。

## ✨ 功能特性

- **深度解析**：将英文文章智能分句，一键获取每句的**词性分析**、**语法结构**、**知识点**和**中文翻译**
- **词性高亮**：10 种词性（名词、动词、形容词等）以不同颜色高亮显示，支持自定义颜色和筛选
- **全文翻译**：整篇文章一键翻译，同时自动缓存每句翻译结果
- **生词本管理**：
  - 多生词本支持（创建、重命名、删除、合并）
  - 单词卡片式展示，支持编辑、删除、批量操作
  - 右键/长按单词快速添加到生词本
  - 导入/导出（JSON / Markdown / TXT 格式）
- **记忆模式**：
  - **闪卡模式**：3D 翻转卡片，按掌握度评级（已掌握/模糊/不认识）
  - **填空练习**：根据中文释义拼写单词，逐字母提示，连击奖励
  - **听写练习**：听发音拼写单词，支持音节提示和语速调节
  - **选词练习**：四种模式（看释义选词 / 听音选词 / 看词选义 / 听音选义）
  - **听力练习**：听单词选正确选项，支持输入和选择两种模式
  - **语境填空**：基于历史文章，在原文上下文中填空记忆生词
  - **全文回顾**：生词可点击查看释义，支持全文朗读
  - **逐句精读**：逐句展示分析结果，左右键切换
- **学习统计与计划**：
  - 今日/总体学习数据（单词数、掌握率、连续天数）
  - 各模式学习次数统计
  - 每日目标设置与学习提醒
- **历史记录**：自动保存每次分析结果，支持回顾、删除和清空
- **主题切换**：浅色/深色模式，切换时带有水波扩散动画
- **响应式设计**：适配桌面、平板和手机屏幕

## 🏗 技术栈

- **语言**：原生 JavaScript (ES6+)、CSS3、HTML5
- **架构**：模块化设计，基于 `ModuleRegistry` 的依赖注入
- **数据持久化**：LocalStorage（API 配置、生词本、历史记录、学习统计）
- **语音合成**：Web Speech API（单词发音、全文朗读）
- **动画**：CSS Transitions / View Transitions API（主题切换）
- **兼容性**：支持现代浏览器（Chrome / Firefox / Edge / Safari）

## 🚀 快速开始

### 1. 克隆或下载项目

```bash
git clone https://github.com/your-username/english-lab.git
cd english-lab
```

### 2. 启动本地服务器

由于使用了 `localStorage` 和 `fetch` 加载词库，建议使用本地 HTTP 服务器（而非直接打开文件）：

```bash
# 使用 Python 3
python -m http.server 8000

# 或使用 Node.js
npx serve .
```

### 3. 打开浏览器

访问 `http://localhost:8000` 即可使用。

### 4. 配置 API Key

点击右上角 **⚙️ 设置** 按钮，填入你的 API Key（支持 OpenAI 兼容接口，默认使用 DeepSeek API）：

- **Base URL**：`https://api.deepseek.com`（可自定义）
- **API Key**：你的密钥
- **模型**：`deepseek-chat`（可自定义）

保存后即可开始使用深度解析和例句生成等功能。

## 📖 使用指南

### 深度解析

1. 在文本框中粘贴英文文章
2. 点击 **解析** 按钮，系统将自动分句并显示句子卡片
3. 每张卡片下方有 **词性**、**语法结构**、**知识点**、**翻译** 四个按钮，点击即可查看对应分析
4. 点击 **词性高亮** 按钮可开关高亮，右键/长按该按钮可自定义词性颜色
5. 点击 **全文翻译** 区域可查看整篇翻译

### 生词本

- 点击主菜单 **生词本** 进入
- 创建多个生词本，每个生词本独立管理单词
- 在文章句子中 **右键/长按** 单词可快速添加到生词本
- 支持批量操作、导出/导入（JSON / MD / TXT）

### 记忆模式

- 点击主菜单 **记忆模式** 进入
- **单词模式**：选择生词本，然后选择闪卡/填空/听写/选词等练习
- **文章模式**：选择已解析的历史文章，然后选择语境填空/全文回顾/逐句精读
- 所有练习均包含 **计分、连击、彩蛋反馈** 等激励机制

### 学习统计与计划

- 在记忆模式界面点击 **学习统计** 可查看每日/总体数据
- 点击 **学习计划** 可设置每日目标、学习提醒和复习间隔

## 🛠 开发指南

### 模块注册

所有模块通过 `ModuleRegistry` 注册，依赖注入方式：

```javascript
ModuleRegistry.register('MyModule', ['Dependency1', 'Dependency2'], function(Dependency1, Dependency2) {
    // 模块实现
    return { /* 公共接口 */ };
});
```

### 添加新功能

1. 在对应目录创建新文件
2. 使用 `ModuleRegistry.register` 注册模块
3. 在 `index.html` 中添加 `<script>` 引用
4. 如需新增主按钮，通过 `MainButtonManager.addButton()` 动态添加
5. 如需新增设置项，实现 `fillXXXSettings` 函数并在 `settings_ui.js` 中调用

### 样式规范

- 所有样式使用 CSS 变量（`var(--accent)` 等），支持深色模式
- 组件样式放在 `assets/css/components/` 下
- 功能样式放在 `assets/css/features/` 下
- 修改前请阅读 `assets/css/README.md`（如有）
