安装说明

  1. 确保 Native Host 程序已安装到系统中

  2. Native Host 清单文件位于 Chrome 的 NativeMessagingHosts 目录：

    {
  "name": "com.englishlab.nativehost",
  "description": "English Study Club Native Host",
  "path": "C:\\path\\to\\native-host.exe",
  "type": "stdio",
  "allowed_origins": [
    "chrome-extension://<extension-id>/"
  ]
}

  3. 清单文件应放置在以下位置之一：

    • Windows: HKCU\Software\Google\Chrome\NativeMessagingHosts\com.englishlab.nativehost
    • macOS: ~/Library/Application Support/Google/Chrome/NativeMessagingHosts/com.englishlab.nativehost.json
    • Linux: ~/.config/google-chrome/NativeMessagingHosts/com.englishlab.nativehost.json
