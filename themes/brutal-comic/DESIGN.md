# 硬边漫画 Brutal Comic · 主题设计文档

> 「印刷漫画的一张皮」——精读工具换上硬边漫画外衣：卡片如贴纸、按钮如印章、徽章如漫画对话气泡，阅读仍是第一优先级。

## 一、设计基调

* **粗野主义 × 硬边漫画**：零圆角、粗黑描边、无模糊的偏移硬阴影、纯色块 + 网点印刷纹理。

* 明确拒绝：圆角卡片、柔阴影、玻璃/渐变/磨砂、发光光晕。

* 色彩语言：漫画三原色——**红**（主强调/危险）、**黄**（点缀/主 CTA）、**蓝**（辅助/分区）；**墨黑**（描边与文字），**暖纸白**（底面）。

## 二、语义色变量（`--brutal-*`）

| -------------------------- | --------- | --------- | ----------- |

| `--brutal-paper`           | `#FFFDF7` | `#0B0B0D` | 卡片/弹窗/输入近白底 |
| `--brutal-paper-warm`      | `#F2EBD9` | `#141417` | 暖纸面（侧栏/面板）  |

| `--brutal-red-deep`        | `#B82E22` | `#E23B2C` | 红 hover     |
| `--brutal-yellow`          | `#FFD23F` | `#FFD23F` | 点缀 · 主 CTA  |
| `--brutal-blue`            | `#2F6FCB` | `#6E8DF0` | 辅助 · 分区     |
| `--brutal-soft`            | `#F4ECD7` | (暗纸)      | 柔暖悬停底       |

| `--brutal-shadow-sm/md/lg` | 偏移硬影      | 偏移硬影      | 无模糊阴影       |

这些语义色只定义语义，最终由各平台的**主题变量层**（`--study-*`、`--shadow-*`）消费。

## 三、集成契约

* 所有规则都挂在 `html[data-theme-plugin="brutal-comic"]` 前缀下；仅启用该主题时生效，**互不污染**。

* 由 [themes/theme\_plugin.js](../theme_plugin.js) 动态 `<link>` 注入；删除本目录 → 加载失败即自动回退，不触碰任何原样式文件、不残留内联样式。

* 平台分层：

  * **桌面端**：`html` 无 `data-platform`，只命中桌面变量块（变量层 + 第 16–17 节组件覆盖）。

  * **移动端**：`html[data-platform="mobile"]`，命中 `.esc-*` 组件块（第 18 节）。

* 深色模式：随 `html[data-theme="dark"]` 切换，覆盖墨纸两套语义色。

## 四、结构（theme.css 章节）

| 节    | 内容                                                 |
| ---- | -------------------------------------------------- |
| 1–2  | 变量层 · 亮 / 暗（`--study-*`、`--radius-*`、`--shadow-*`） |
| 3    | 标题黑体（Impact/黑体系）                                   |
| 4    | 浏览器表面：selection / focus / 滚动条                      |
| 5–14 | 卡片、按钮、输入、弹窗、侧栏、顶栏、徽章、状态、设置、阅读区                     |
| 15   | 硬弹入动画                                              |
| 16   | 全面硬边化兜底（`!important` 清零圆角、硬阴影、去玻璃/发光/渐变）           |
| 17   | 漫画活力增强（撞色条、实心彩色徽章、主 CTA 黄、按压动效、网点）                 |
| 18   | 移动端叠加层（`[data-platform="mobile"]`，`.esc-*`）        |

## 五、覆盖策略

* 变量层优先：能在 `--study-*` 变量层解决的就不要写组件选择器。

* `!important` 集中在第 16 节兜底，用于覆盖组件里写死的圆角/柔影/玻璃/渐变。**新组件若走变量通道则无需** **`!important`**；后续可逐步把兜底收敛为精确选择器（v2）。

* 已显式豁免：`--brutal-pl-spin` 不变量（spinner 保留圆形）。

## 六、注册 / 新增主题

* 主题清单唯一来源：`themes/index.json`（清单注册表）。

* 入口页（`index.html` 与 `mobile/index.html` 的 `<head>`）在 `window.THEME_PLUGIN_THEMES` 注入同一批主题，供加载器同步读取（head 内同步执行以消除闪烁）。

* **新增主题步骤**：创建 `themes/<id>/`（含 `theme.css` + 本 `DESIGN.md` 样式的设计文档）→ 在 `index.json` 追加 → 在两端入口页 `THEME_PLUGIN_THEMES` 追加同位记录。
